# Specifications Directory

This directory is where you should save all the specifications created during the workshop.

## Purpose
- Store specifications generated by the agent from `@docs/prds/` files
- Keep all workshop specs organized in one location
- Reference during implementation exercises

## How to Use
1. Prompt the agent to write a spec from a requirements file, e.g. `Write a CustomerCard spec based on @docs/prds/PRD-001-customer-card.md and save it to specs/SPEC-001-customer-card.md`
2. Review the generated spec for Context, Requirements, Constraints, and Acceptance Criteria
3. Name the file with the `SPEC-NNN-[feature].md` convention (see below)

## File Naming Convention
Specs use `SPEC-NNN-[feature].md`, where `NNN` is a zero-padded 3-digit sequence
ordered by when the feature is introduced (spec order follows the exercise
chronology). Numbers are stable once assigned — supersede rather than renumber.
See [GUIDE-008 Documentation Standards](../guides/GUIDE-008-documentation-standards.md).

- `SPEC-001-customer-card.md`
- `SPEC-002-customer-selector.md`
- `SPEC-003-health-score-calculator.md`
