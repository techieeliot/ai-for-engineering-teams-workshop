# Requests for Comments (RFCs)

Proposals under discussion — changes not yet decided. An RFC captures a problem,
options, and a recommendation; once accepted, the outcome is usually recorded as
an [ADR](../adrs/README.md) and/or a [spec](../specs/README.md). Conventions: see
[GUIDE-008 Documentation Standards](../guides/GUIDE-008-documentation-standards.md).

Naming: `RFC-NNN-kebab-title.md`. Numbers are stable once assigned.
