# Architecture Decision Records (ADRs)

Decisions of record for this project. Each ADR captures the context, the
decision, and its consequences. Format and naming: see
[GUIDE-008 Documentation Standards](../guides/GUIDE-008-documentation-standards.md).

Naming: `ADR-NNN-kebab-title.md`. Numbers are stable; supersede rather than
renumber.
