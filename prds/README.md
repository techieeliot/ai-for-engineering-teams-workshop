# Product Requirements (PRDs)

Product requirements — the "why/what" for each feature. PRDs are the **input to
specs**: a `SPEC-NNN` is generated from the matching `PRD-NNN`. Naming and
conventions: see [GUIDE-008 Documentation Standards](../guides/GUIDE-008-documentation-standards.md).

Naming: `PRD-NNN-kebab-concept.md`. Numbers mirror the derived spec
(`PRD-001` → `SPEC-001`) and are stable once assigned.
